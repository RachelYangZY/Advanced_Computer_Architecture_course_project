Quantized DeiT-Tiny on bare-metal RV64IMC with xqmac8 + xrequant

Everything built so far: model export, TFLite-to-C generator, B0/B1/X1 kernels, custom instructions, Spike verification and measurements.

DeiT-Tiny (patch 16, 224x224), 5.7 M parameters, 1.25 GMAC per image. FP32 weights from a safetensors file (access-restricted, not committed).

3. TFLite → integer-only C generator done, bit-exact

parse flatbuffer (tflite_ir.py) → lower each op: Q31 multipliers, lookup tables, strides, folded bias bias_eff = bias - zp_in * sum(w) → plan memory (RESHAPE aliases, greedy-by-size arena) → emit weights.c, model.c, harness.c, model_io.c.

Reproduces TFLite's fixed-point math exactly: srdhm + rounding shift (FC/CONV half-up, ADD/MUL/BMM half-away), MEAN single/double rounding, integer softmax, table RSQRT/GELU. Whole model: logits identical to the TFLite interpreter on the tested inputs; BMM/softmax intermediates differ by ≤0.01% at rounding ties.

tools/tflite2c/gen_model.py dump_ref_tensors.py scripts/run/gen_check.sh · docs: docs/GENERATOR.md
↓model.c calls op_*_i8 kernels

4a. Kernel libraries done

B0 baseline: ops_ref.c, -O2, plain loops.
B1 software-optimized: ops_opt.c, 2 rows x 4 channels blocking, im2col, packed BMM operands, folded zero points.
X1 = B1 + xqmac8 dot products + xrequant.
X1MAC = xqmac8 only, software requant.

Override mechanism: weak symbols op_fc_i8 / op_bmm_i8 / op_conv2d_i8 in the reference library are replaced by the optimized ones.

4b. Custom instructions done in Spike

xqmac8 rd, rs1, rs2 (custom-0, funct3 0): rd += sum of 8 int8 x int8 lane products, 64-bit accumulator.
xrequant rd, rs1, rs2 (funct3 1): (acc * multiplier) via TFLite-exact SRDHM + rounding shift + zero point + saturate to int8; mode 1 half-up, mode 2 half-away.

Both read three registers (rd is an input) — a design risk for a 2-read-port register file in RTL. See DESIGN.md.
↓Spike extension + verification

5. ISA implementation and verification done

Spike extension src/spike_ext/xqmac8_spike.cc (installed by scripts/setup/install_xqmac8_spike.sh). C oracle src/kernels/xrequant_ref.h. Host check against TFLite helpers: 20 M random cases. Spike: directed + randomized tests, seeds 1-3, every executed custom instruction compared to the oracle. Result: pass.

scripts/run/verify_isa.sh → results/isa_verify.log

7. Instruction-mix analysis done

Whole model via Spike PC histogram + disassembly (instr_mix.sh); per-stage mix by differencing histograms at op boundaries (op_mix.sh). Findings: in X1, xqmac8 is 10.3% of instructions and xrequant only 0.39%; ALU 56%; non-GEMM ops (ADD, MUL, SQDIFF, TRANSPOSE, SOFTMAX, MEAN...) are about half of X1's instructions — the next bottleneck.
